# ADR 0005 — Nom de l'application : LePalier (3 octobre 2026)

Note : d'abord envisagé en deux mots (« Le Palier »), retenu en un seul mot « LePalier » le 3 octobre 2026.

Statut : accepté. Décision : l'application s'appelle **LePalier** (le palier = l'espace commun entre les étages d'un immeuble ; court, sans jargon, facile à dire à un associé peu à l'aise avec l'informatique). À vérifier avant tout usage public : disponibilité du nom de domaine, du dépôt GitHub et absence de marque antérieure gênante ; aucune de ces vérifications n'a été faite à la date de la décision. Impact : README, CLAUDE.md, noms de projets Compose (`lepalier-dev`, `lepalier`), LEXIQUE (écriture du nom), objets et en-têtes d'e-mails à l'écran.
